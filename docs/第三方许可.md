## FFmpeg 修改与依赖范围

`filehub1` 是修改后的构建，不代表未经修改的官方二进制。`ffprobe/filehub.patch` 包含两项修改：兼容只有中文输出资源的 MSVC 编译器识别；把 MOV `chnl` 读取函数返回值正确传递给调用者，避免未初始化返回值。构建脚本还把生成配置中的编译器描述规范成 ASCII，以供 Windows RC 编译器读取。完整构建命令保留在 `ffprobe/build-recipe/`。

启用 FFmpeg 自带解复用器、解码器与解析器；关闭外部库自动探测、网络输入、编码器、封装器、设备/滤镜和无关图像变换库。随包是 `ffprobe.exe`、`avcodec-62.dll`、`avformat-62.dll`、`avutil-60.dll`。这些组件独立于 FileHub 进程运行，DLL 可用兼容的修改版本替换；FileHub 不限制 LGPL 库的修改、替换或为调试修改而进行的逆向工程。

最初下载的 BtbN LGPL3 shared 候选包没有进入交付：它静态包含大量额外库，单独的 LGPL 标签不足以完成全部依赖的源码与版权闭合。原先 Inno 7.1.0 候选也没有采用，因为可用解包工具不支持其格式，已改用固定的官方 6.7.3 版本。

## 离线对应源码与替换说明

程序目录 `_internal/third_party/sources` 随包保存 FFmpeg、QtBase 和 PySide 6.11.2 的三个未经修改上游源码 ZIP；QtImageFormats 6.11.2 完整源码另存于 `_internal/third_party/conversion/sources`。`third_party/components.json` 记录下载 URL、精确源码 commit/tag、ZIP SHA256、二进制 SHA256 和构建依赖版本。FFmpeg 的本地补丁与构建配方另外随包保存。无需联网即可取得对应源码；再次分发本安装包时请同时保留这些材料。

FFmpeg 可按随附配方使用开发用 MSVC x64、Git Bash 与 GNU make 重建，或在其他工具链下从相同源码构建兼容 DLL。退出 FileHub 后替换 `_internal/resources/ffprobe` 内整组兼容二进制。Qt / PySide 可从随附源码和 [Qt 构建文档](https://doc.qt.io/qt-6/build-sources.html)重建，退出程序后替换 `_internal/PySide6` 内对应 DLL/插件。保持 ABI 兼容；FileHub 不实施阻止这些替换的签名检查。原始安装包可用于恢复原版本。

WebP 插件位于 `_internal/PySide6/plugins/imageformats/qwebp.dll`，保持动态可替换。重建方法见 `_internal/third_party/conversion/README.md`。本轮不添加视频编码器、OpenH264 或视频转换依赖；原有 ffprobe 只用于视频归档探测。插件的 libwebp 随 Qt 上游构建内嵌，完整对应源码及 BSD 版权／专利材料一并提供。
