# FileHub Windows 0.3.1 交付说明

0.3.1 恢复原来的右键手动标签用法：已有项目配置时，多选文件并使用 Explorer 的 FileHub 入口，直接输入项目代码/目的地或点击最近口令。旧定义尚未迁移或尚未授权时，在同一窗口确认一次“恢复手动标签归档”，然后预览、归档；输入、历史与文件选择保留，支持删除单条历史与清空全部，无需重写规则。主界面“文件处理”继续提供 0.3.0 的通用外部规则处理。

恢复只新增手动标签权限，不开启普通自动规则、观察目录或其他未授权功能。同一已选方案保留原有明确授权；多个方案须自行选择，切换方案会说明原项目规则关闭的影响。恢复写入部分成功时重新读取实际设置，允许在原窗口再次明确确认。归档已持久完成后退出应用，也会正确确认发送队列。

安装包、离线指南和校验文件入口为 [0.3.1 版本页面](https://github.com/Wanrd0Geri/filehub-windows/releases/tag/v0.3.1)，需仓库访问权限。本说明记录本地构建与验证结果，发布成功及远端 SHA 由发布记录另行证明。0.2.0、0.2.1、0.2.2、0.3.0 安装器保持原样。
