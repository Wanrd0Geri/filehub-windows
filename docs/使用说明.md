# FileHub Windows 0.1.0 使用说明

## 安装与第一次启动

运行安装器，按当前用户安装。桌面快捷方式、右键“送进项目…”和登录启动均可选，默认不勾选；安装结束不会自动启动。开始菜单有普通 FileHub 和隔离演示两个入口。演示只使用新建示例目录，不会把真实桌面、下载或同步目录作为素材。

普通入口首次启动未配置目录，自动整理暂停。设置里的“同步根目录”通过任意分类下的 `分类/项目/YYMMDD_项目代码_项目名` 发现项目，例如 `1_工作/项目/261001_LYX_临渊行`。监控目录应放在同步根目录之外，也不得与本地状态目录重叠；不能选择磁盘根目录。先保存设置，再按需求取消暂停。

右键集成在 Windows 11 通常位于“显示更多选项”。登录启动进入托盘；没有配置或暂停时不会自动整理。设置窗口也可以开关这些当前用户集成。已有同名外部注册项或被修改的命令会保留并显示问题，不能擅自覆盖。

## 手动归档与口令

选择素材后打开“送进项目”，输入口令并检查预览。预览捕获源创建时间并展示拟归档目标，执行时重新核对源与目标占用，必要时重新分配空闲版本；执行前如果源文件被修改，程序停止对应操作，避免按旧计划误处理。Windows 复制／同步工具可能改变创建时间，先核对预览中的日期；电脑关机时不能处理任务。

| 口令示例 | 结果 |
| --- | --- |
| `LYX020822` 视频 | `3_制作/E02/S08/02_08_22_01_日期AM或PM_1080p.mp4`；真实视频宽度决定标识，1920 对应 1080p |
| `LYX020815+20` 视频 | 两镜分别留文件，先复制，再移动；统一批次可撤销 |
| `LYX020815+16+17` 视频 | 三镜及以上只保留第一镜母文件，并提示通知制片 |
| `LYX020822` PNG | `E02S08_C022_日期-1.png` |
| `LYX苏云法相` | 依已有目录匹配：已有完整“苏云法相”则保持角色名；只有“苏云”则“法相”作为备注，以预览为准 |
| `LYX破败庠序` | 场景“庠序”，备注“破败” |
| `LYX角色新角色` | 新角色目录及对应素材名 |
| `LYXPV决战` | `3_制作/PV`，带“决战”备注 |

视频序号 `_01`、`_02` 与图片版本 `-1`、`-2` 用于避开既有目标。不同内容才产生后续版本；项目内发现相同主内容时保留已有项目文件并把重复源送到回收站，结果中显示已有文件路径。命名口令无效时源文件保持不变，同一未变化问题不会反复通知。

## 自动整理与三天缓冲

程序运行且电脑唤醒时，每十分钟检查一次。本机监控目录素材从首次看到且稳定开始计算完整缓冲期，默认三天；旧创建时间或旧修改时间不会使第一次见到的文件立即过期。暂停期间不处理，恢复后重新观察稳定时间。正在写入、锁定、下载临时文件或不安全路径不会被强行整理。

本机监控素材满缓冲期后移入同步根目录的 `0_收件箱/图片|视频|其他/当天YYMMDD日期`。监控目录中精确识别的 `.baiduyun.uploading.cfg` 残留也须稳定满缓冲期才回收。

高级全局任务默认关闭。启用后会回收共享收件箱中到期的日期目录，并修正整个同步根目录内的不合规名称（包括已有项目）。共享全局整理默认由 Mac 负责，只能指定一台电脑启用，避免双机同时清理。收件目录过期按整棵树保留回收边界，包含空目录；新到达或发生变化的内容受到保护。不要把需要长期保留的共享资料随意放入会到期的收件目录。

两台电脑共享同一镜头时，请保持同一时段只有一个写入者。本版本没有承诺双机原子协调；真实 Mac／Windows 百度同步尚未实测。

## 历史、撤销与回收站

统一历史持久保存归档、复制、移动、回收与撤销状态。普通复制／移动可选择批次撤销；原位置被占用、输出被改写，或复制输出已是唯一内容存活者时拒绝危险撤销并保留内容。跨盘移动也复制并核对主内容、命名流与时间，再移除源。

回收动作不能自动撤销。历史显示回收时的暂存名称及原路径；从 Windows 回收站“还原”对应项后，核对内容，再把带 `.filehub-…` 的暂存名称改回原名称。不要按模糊名称还原或删除其他回收站项目。

失败或中断后历史可能显示部分完成／冲突，请按其中的源、目标、暂存路径核对现存内容；不要手动删除唯一存活文件。

## 托盘、升级与卸载

关闭窗口只是隐藏到托盘，自动整理按当前暂停状态继续。再次打开入口会显示现有窗口；真正退出请用托盘“退出 FileHub”，等待工作结束。程序运行时安装器和卸载器拒绝继续，不会强杀进程。

普通状态默认位于当前用户 `%LOCALAPPDATA%/FileHub`（以程序实际状态路径为准）；使用 `--state-dir` 时位于指定独立目录。升级保留设置和历史，安装过程不自动运行。卸载删除程序和属于此安装的快捷方式／注册项，保留程序目录之外的状态、历史、项目与源文件；被外部修改的注册命令保留。卸载不是清空素材的操作。

便携版请保留整个目录；第三方材料在 `_internal/third_party`，ffprobe 在 `_internal/resources/ffprobe`。本版本不下载字体，使用已安装字体及系统回退。
