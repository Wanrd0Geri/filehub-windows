Source local timezone datetime derives from captured fingerprint creation time by default; optional injected provider must return aware datetime. Execution uses captured time and width, never recaptures source time. Engine and service history both expose original UTC ISO batch timestamp without UI SQL.
- Backward-compatible engine extension `.execute(operations,label,*,batch_id=None)`: supplied batch must exist; append only new typed operations, execute only appended rows, preserve original timestamp/label. `Journal.append_operations(batch_id,operations)->list[str]` validates batch before insert. This supports one selection/one journal batch with sequential locked dedup and unified reverse-order undo. Prior committed/conflicted operations are never re-executed by append.

## Execution and safety contract

Shared engine lock covers source identity revalidation, project discovery, current destination allocation, primary-stream duplicate scan, and each action. Existing candidate guard rechecks content after scan and stays held through recycle; selected source identities (including hardlink aliases) are excluded as original survivors. Subsequent same-content selected inputs see already committed first output and recycle once. Candidate disappearance/changes are skipped; hidden/reparse files and directories are excluded. Failed first action does not authorize recycling the next source against absent output. Recycle errors preserve sources through existing engine behavior. Only generated supplemental copy bypasses dedup.

One selection creates one typed batch. Ordinary two-shot actions are `copy(secondary)` then `move(primary)`; undo restores primary before removing unchanged supplemental copy. Duplicate-to-recycle deliberately retains existing engine manual-restore semantics, surfaced in history on undo. Source fingerprint includes all streams for identity and safe engine transfer; business duplicate comparison is only `same_primary_content`.

Remaining downstream scope: directory archive support remains explicitly rejected by ordinary-file Fingerprint/engine at this stage; scheduler/folder safety comes in Task 4. UI rendering/notifications come in Task 5. Native binary licensing/offline bundle comes in Task 6. No package-ready claim.
