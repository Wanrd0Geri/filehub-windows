# FileHub 0.2.0 交付与限制

安装器目标：`dist/installer/FileHub-0.2.0-windows-x64-setup.exe`。便携版需保留整个 `dist/FileHub/`；最终文件哈希、大小与验收结果见 [包装报告](reports/rules-020/task5-sol.md)。本阶段只准备构建输入，最终安装器尚待产品冻结后构建验收。

升级由你自行执行：从托盘退出旧版，等待整理结束，运行新安装器，按需勾选右键菜单、桌面快捷方式和登录启动。安装器复用原安装位置，保留程序目录之外的原设置、历史、项目及源文件；安装结束不会自动运行。无需卸载旧版或清空状态。本轮未对正在使用的 FileHub 进行安装、升级或卸载，也未改实时注册表。

0.2.0 增加项目模板、有序自动规则和静态 JPEG／PNG／WebP 转换。新建、复制、导入规则默认关闭；明确保存／启用并取消暂停才自动运行。普通规则不需要同步根目录，按自身条件处理配置监控目录的顶层项，每约十分钟检查。空规则和内置默认模板保留旧版归档行为。

图片默认保留原图，替换需明确选择；同格式重压缩与跨扩展名替换均先生成验证、备份再提交。备份位于状态目录 `conversion-backups`，本版本不自动清理，撤销依赖完整备份。输出改写或原路径占用等冲突会保留数据并提示核对。

支持静态 JPEG／PNG／WebP，4000 万像素／256MiB 上限且受内存约束。透明图转 JPEG 可选背景；元数据与专业色彩保真不保证。动画／多页、16 位 PNG、RAW／HDR、视频转换、OCR、脚本、上传、递归监控、双机原子协调不在本版本支持范围。原有视频归档仍通过 ffprobe 探测。原生编解码取消可能需等待当前调用返回。

本轮实际验收只使用隔离的便携程序和自有 UUID 状态／素材，源码测试另列。旧版 0.1.0 安装／卸载及 0.1.1 补丁证据是历史记录，不代表 0.2.0 已重复这些操作。Windows 10、全新虚拟机、Mac 与真实双机百度同步未验证。
