# FileHub Windows 0.2.2 交付说明

本版修正图片转换同名目标的版本续接，并对设置天数框及滚动条做小范围外观调整。

另存及跨格式转换遇到已占用的 `图片-6.png`，续接为 `图片-7.png`；已有 `图片-9.png` 时续接为 `图片-10.png`，不会重复追加 `-1`。预览固定最终目标；执行时目标被后来占用或源文件变化，停止该项并要求重新预览，不覆盖现有文件。同格式原地替换仍保留完整备份与撤销保护。独立图片转换及规则中的图片转换使用相同原则。

设置中两个天数输入框去掉上下箭头，保留 1–365 天范围、直接输入及键盘调整。全局滚动条采用细圆角滑块、安静轨道与深浅主题悬停色，保留滚轮、拖动和键盘操作。

实际安装器 `FileHub-0.2.2-windows-x64-setup.exe` 为 143140953 字节，SHA256 `705bf74f3567c73fe152e907d0726a438a1784b0f1ffac58c83886c74b7fc33f`。便携 EXE 为 2566737 字节，SHA256 `1bd22a1ee6574dbd5ed63c7c243c378dd66414c6e9c1ef4ce3bbd98203a272af`。实际 EXE 隔离自测 23 项通过；root 全套源码测试 733 项通过。两类证据范围不同，具体构建与验收记录见 [0.2.2 包装报告](reports/rules-022/packaging-sol.md)。便携使用须保留完整 `dist/FileHub/`。旧版 0.2.1 与 0.2.0 交付材料保持原样。

升级由你自行执行：从托盘退出旧 FileHub，等待工作结束，再运行 `FileHub-0.2.2-windows-x64-setup.exe`。本轮不执行安装、升级、卸载或修改实时注册项。

安装器和安装说明已保存至 `F:/FileHub交付/0.2.2`，复制后 SHA256 一致。root 独立核对 47 个打包模块与冻结源码、版本及依赖材料通过，见 [最终审查](reports/rules-022/final-astra-review.md)。

图片元数据可能丢失，备份不会自动清理；视频转换、动画／多页、RAW／HDR 不支持。Windows 10、全新虚拟机、Mac 和真实双机同步未验证。
