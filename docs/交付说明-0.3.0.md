# FileHub Windows 0.3.0 候选交付说明

本候选版将规则定义改为外部 UTF-8 JSON：导入、绑定、本机启用、预览、执行与记录由 FileHub 负责，编写交给使用者或外部 AI。正常界面为文件处理、规则文件、图片转换、记录、设置；没有规则/项目模板编写器、主页演示按钮或安装器演示快捷方式。

当前远端 main/已发布版本仍为 0.2.2。本页记录待审 0.3.0 源码及打包约定，尚未确认实际 0.3.0 构建、安装器或发布；最终交付负责人完成审计后补充具体路径、SHA256、EXE 结果及发布状态。历史 0.2.x 安装器与报告保持原样。

协议为 `filehub.rules` 整数版本 1。导入/替换/恢复/迁移后规则默认关闭；本机绑定不包含在导出文件，也不添加观察目录。无匹配不操作；个人归档兼容档案及三个权限需要显式选择，默认不恢复旧行为。

离线指南包 `FileHub-rule-guide-v1.zip` 包含指南、schema、五份示例和 manifest，共 8 项。安装目录内静态 Help 为 `help/AI规则编写指南.md`、`help/filehub-rules-v1.schema.json` 与 `help/examples/*.json`，共 7 项。打包示例不安装、启用或执行这些规则，无需私有仓库或联网使用。

[明确运行模块与 Help 清单](../packaging/runtime-inventory.json) 是构建输入。清单包含运行服务、操作/历史/恢复、自动处理、图片转换、外部协议/目录册/编译/兼容/迁移、UI 与 0.2/0.3 工程自检；`ui.action_editor` 保留图片转换字段。不可到达的旧 `ui.templates_page`、`ui.condition_editor` 排除；源码命令行验证入口 `filehub.rulefiles.__main__` 只供源码/测试使用，同样不进入 EXE。清单按源码成员核对，不沿用旧固定 47 模块计数。

工程 EXE 验收保留既有 23 项真实归档、视频探测、图片转换/备份/撤销检查，增加 7 项外部目录册导入/绑定/启用、手动预览、真实移动、撤销、非法替换不改字节、空目录及无匹配不回退检查。冻结版另检查静态 Help 存在、示例通过同一解析器且没有自动安装。通过数与实际 artifact 证据等待最终构建确认。

沿用现有 pinned Python 3.12.10、Qt/PySide6 6.11.2、ffprobe、已审 WebP 插件和离线许可/对应源码材料，不改工具链。按当前用户安装，不自动启动，不删除用户状态。构建使用明确源码路径与禁止 bytecode，artifact manifest 仅收录本轮 EXE、0.3.0 安装器及指南 ZIP，历史安装器不混入本轮清单。

Windows 10、全新虚拟机、实际安装/升级/卸载、Mac 与真实双机同步尚未在本候选轮验证。实际新版本完整源码测试、PYZ/资源独立审计、EXE 自检及哈希由最终报告给出；此页不提前宣称通过。
