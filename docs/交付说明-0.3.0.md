## 规则与离线指南

协议为 `filehub.rules` 整数版本 1。导入/替换/恢复/迁移后规则默认关闭；本机绑定不包含在导出文件，也不添加观察目录。自动处理按规则文件优先顺序、文件内规则顺序匹配。无匹配不操作；个人归档完整兼容档案及三个权限需要显式选择，默认不恢复旧行为。

离线指南 ZIP 包含指南、schema、五份示例和 manifest，共 8 项。包内静态 Help 为 `help/AI规则编写指南.md`、`help/filehub-rules-v1.schema.json` 与 `help/examples/*.json`，共 7 项；实际 EXE已经核对存在、解析示例，并确认它们未自动安装。无需私有仓库、API Key或联网使用。

[运行模块与 Help 清单](../packaging/runtime-inventory.json) 包含服务、操作/历史/恢复、自动处理、图片转换、外部协议/目录册/编译/兼容/迁移、UI与0.2/0.3自检。`ui.action_editor` 保留图片转换字段；不可到达的旧 `ui.templates_page`、`ui.condition_editor` 及仅供源码验证的 `filehub.rulefiles.__main__` 明确排除，已独立核对包内不存在。

沿用 pinned Python 3.12.10、Qt/PySide6 6.11.2、ffprobe、已审 WebP插件和离线许可/对应源码材料，没有改变工具链。普通用户使用安装器或完整便携目录，不需 Python或开发依赖。

Windows 10 22H2 x64及以上为安装器目标；本轮未验证 Windows 10、新虚拟机、实际安装/升级/降级/卸载、Mac与真实双机同步。未操作现有应用、实时注册项、用户观察目录或真实素材，未在本轮实现端执行 push/release。
