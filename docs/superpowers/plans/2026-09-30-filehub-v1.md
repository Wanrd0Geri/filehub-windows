# FileHub Windows v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付离线可用、无需自行安装 Python 的中文 FileHub Windows 安装包。

**Architecture:** Python 3.12 规则核心与 Windows 平台适配分离；SQLite typed journal、跨进程本机锁与文件指纹保护所有操作。PySide6 Widgets 自定义样式复现确认的炭黑工作台，避免 QML/Python 双模型复杂性；PyInstaller onedir + Inno Setup 当前用户安装。

**Tech Stack:** Python 3.12, PySide6, SQLite, ctypes Windows APIs, ffprobe, pytest, PyInstaller, Inno Setup.

**Spec:** `docs/superpowers/specs/2026-09-30-filehub-v1-design.md`; 精确规则输入为 `reference/mac/filehub_打包_260930/Windows版文件自动收纳-需求文档.md` 与同目录 `脚本/filehub.py`（只读，不执行）。

## Global Constraints

- 中文 UI，整理/收件箱/记录/设置四入口，炭黑暖黄、紧凑间距，浅色/系统主题，右键小窗口。
- v1 只归档，无长期选定标签、规则编辑器、Mac 改动和远程发布。
- 全部实现者 GPT-6.1 Sol；Astra 技术负责人分阶段审查；用户已委托常规技术审批。
- 所有测试在 workspace 或隔离安装目标内；不得接入真实桌面、下载和同步项目。
- `global_jobs=false` 默认；后台需明确选择目录后启用，首次发现时间决定缓冲期。
- 原子不覆盖；本机操作串行；跨盘复制校验后移除源；回收站失败不得永久删除。
- typed batch journal，移动、复制、回收分别可追踪；撤销保护修改后文件和已占用原位置。
- 崩溃恢复不得丢文件；下载/占用/变化文件跳过；不截断长名，系统超限明确报错。
- 文件创建时间与本地时区在计划时固定；视频探测失败保留源并报错。
- Mac 原规则为基线，明确修正 PV/正片镜号丢失、合镜撤销、截名和并发版本分配。
- 双机异步网盘无实时锁：同一镜头单写入者限制需进入说明。
- 字体优先 Inter + Noto Sans SC，可在许可证核对后随包；否则用已安装字体与系统回退，无运行时外部网络字体；ffprobe 和 Qt 等许可证随包。

## Review Focus

1. 崩溃恰在写目标、写 journal、删除源之间：状态恢复保留至少一份且不误撤销。
2. 复制完成后源发生变化或目标被替换：指纹不一致时停止，不能移除新内容。
3. 路由文字包含路径穿越、保留设备名、长 UTF-16 名称或重复项目代码：拒绝歧义/越界，不静默改路由。
4. 文件夹含 symlink/junction 或受管目录重叠：不递归越界、不搬项目或自身状态库。
5. 第二进程/右键多选与后台同时归档：统一队列，语义版本连续，不覆盖。

## Structure and interfaces

`src/filehub/` 包：`models.py` 不可变计划/指纹/结果；`journal.py` SQLite；`operations.py` 安全执行与 undo/recover；`platform/windows.py` Windows 锁/文件活动/回收/系统目录；`rules.py` 原规则解析与命名；`service.py` 预览执行协调；`config.py` 持久设置；`scheduler.py` 首次发现与 tick；`ui/` 窗口/主题/控制器；`__main__.py` CLI/GUI 入口；`integration.py` 当前用户右键/自启动；`packaging/` 构建安装；`tests/` 单元与隔离验收。
