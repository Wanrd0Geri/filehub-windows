证据窗口：2026-10-01，本机 Windows 11 x64 build 26200。产品冻结 `fc5a656d03d2f0798eb7c0900399b494ca3a714e`；最后包装修复排除未使用的 Mesa/LLVM 软件 OpenGL，补齐 libmpdec BSD 许可。所有原生操作只使用新建自有测试目录、状态、注册项与测试回收项。
