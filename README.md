# FileHub Windows 0.2.2

把素材按项目口令归档，编辑项目模板，组合文件条件与有序自动规则，并转换 JPEG／PNG／WebP 图片。先预览、再执行，在统一历史中查看和撤销。

## 下载与备份

- [下载 FileHub 0.2.2 安装包](https://github.com/Wanrd0Geri/filehub-windows/releases/tag/v0.2.2)：在 Assets 中选择 `FileHub-0.2.2-windows-x64-setup.exe`，普通使用无需下载源码或配置开发环境。
- [查看所有版本](https://github.com/Wanrd0Geri/filehub-windows/releases)：保存安装包、中文安装说明和 SHA256 校验文件。
- [开发与恢复备份](docs/开发与备份.md)：换电脑后恢复源码、准备构建环境，以及版本发布方法。

本仓库当前为私有备份，仅仓库所有者及受邀协作者可访问。备份包含应用源码、提交历史、需求参考和验证记录；用户自己的素材、电脑上的设置、规则和操作历史不在本仓库中。

## 开始使用

1. 从旧版升级时，先从托盘退出 FileHub，等正在进行的工作结束，再运行从版本发布页面下载的 `FileHub-0.2.2-windows-x64-setup.exe`。按当前用户安装，无需另装 Python 或 ffprobe；保留原设置与历史。
2. 从开始菜单打开 **FileHub 演示（隔离示例）**，先在独立示例里试归档和撤销。
3. 打开普通 **FileHub**，按需设置独立监控目录。项目归档还需同步根目录；普通自动规则不要求同步根目录或口令。首次启动自动整理保持暂停。
4. 先预览目标，再执行。新建、复制和导入的规则默认关闭；保存并明确启用规则、取消暂停后才自动处理。高级全局任务默认关闭。

Windows 10 22H2 x64 及以上为安装器目标。本轮 0.2.2 验证范围以包装报告为准；Windows 10、全新虚拟机、Mac 与真实双机百度同步尚未验证。

关闭主窗口会继续在托盘运行。升级／卸载前，从托盘选择“退出 FileHub”，等整理结束。需要右键入口时勾选“Explorer 右键菜单”。本轮未执行安装／升级／卸载，也未改动现有应用、用户状态或实时菜单。

0.2.2 让图片转换遇到同名目标时自动续接末尾版本号，预览显示固定目标名；设置中两个天数框去掉箭头，所有滚动条采用细圆角样式。

图片转换默认保留原图，另存到所选目录。明确选择“原地替换（可撤销）”后支持同格式重压缩或更改扩展名，保留可恢复原图备份；备份本版本不会自动清理，需预留磁盘空间。支持 JPEG／PNG／WebP，不支持视频转换、动画图片、RAW／HDR 或完整元数据保真。项目模板只影响后续计划；空规则及内置默认模板保持旧版归档行为。
